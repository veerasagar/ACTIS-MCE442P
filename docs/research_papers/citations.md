# Research Papers — Citations & Role

## 1. ReGAIN — RAG + Explainable Network Traffic Analysis

- **Title:** ReGAIN: Retrieval-Grounded AI Framework for Network Traffic Analysis
- **arXiv:** [2512.22223](https://arxiv.org/abs/2512.22223) (Dec 2025)
- **Role:** Foundation for RAG architecture, multi-collection vector DB design, citation-backed LLM reasoning, and data ingestion pipeline.

---

## 2. Tri-LLM — Federated LLM-Based Intrusion Detection

- **Title:** Tri-LLM Cooperative Federated Zero-Shot Intrusion Detection with Semantic Disagreement and Trust-Aware Aggregation
- **arXiv:** [2602.00219](https://arxiv.org/abs/2602.00219) (Jan 2026)
- **Role:** Core reference for federated architecture, trust-aware aggregation, and zero-shot/zero-day detection via multi-LLM semantic prototypes.

---

## 3. CyberRAG — Agentic RAG for Cyber Attacks

- **Title:** CyberRAG: An Agentic RAG Cyber Attack Classification and Reporting Tool
- **arXiv:** [2507.02498](https://arxiv.org/abs/2507.02498) (Jul 2025, revised Sep 2025)
- **Role:** Reference for agentic LLM design — central agent orchestrating modular classifiers, iterative RAG retrieval, structured report generation, and interactive analyst chat.
